# E4 · Integración continua y validación de cambios

**Objetivo:** una comprobación automática que otra persona pueda leer, y claridad sobre qué condiciona el avance de una versión.
**Rama:** `ejercicio-4-ci` · **Requiere:** cuenta de GitHub (o la equivalencia local).

## Qué agrega esta etapa
| Pieza | Qué resuelve |
|---|---|
| `ci.yml` · `on` con `paths-ignore` y `workflow_dispatch` | Se dispara en push, pull request y a mano; cambios solo de documentación no gastan CI |
| `permissions: contents: read` | La automatización solo puede leer el código |
| `concurrency` | Una ejecución nueva cancela la anterior de la misma rama |
| `lint-workflows` (actionlint) | Revisa los propios workflows |
| `matrix` (Python 3.11 y 3.12) con `fail-fast: false` | Misma comprobación en dos versiones; una falla no oculta la otra |
| Cobertura con piso del 25 % | Cuantifica cuánto del código toca el verde (hoy ~32 % de `app/`) |
| Resumen y anotación de error | La ejecución muestra su propio resultado en la página, sin abrir logs |
| Artefactos `salida-pruebas-py3.11` / `py3.12` | La salida de las pruebas queda guardada (v4 exige nombres únicos por job) |
| `construccion` con `needs: pruebas` | Solo corre si todas las pruebas pasaron |
| `promocion` (simulada) + `environment: produccion` | Una promoción a pedido que puede exigir aprobación humana |
| `.github/dependabot.yml` | Propone actualizar acciones y dependencias; el CI las valida |
| `.claude/` y `docs/agente.md` | Skill y comandos para crear, revisar y retar un workflow con un agente |
| `ejemplos/caza-de-errores.yml.txt` | Ocho defectos plantados para encontrar en pares |

## Estado real de esta etapa
| | Estado |
|---|---|
| Pruebas y cobertura en cada push/PR | ejecutado (cuando se sube la rama) |
| Construcción de imagen y reserva real | ejecutado en el job `construccion` |
| Promoción | **simulada** (no publica nada); la aprobación humana requiere configurar el environment |
| Bloqueo de la rama si el check falla | **pendiente**: requiere regla de protección de rama |
| Escaneos de seguridad | **no existen** (primero hay que saber leer esta salida) |
| Secretos | el flujo no usa ninguno |
